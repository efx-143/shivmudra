## 🚩 संस्थेविषयी (About Foundation)

**शिवमुद्रा फाउंडेशन महाराष्ट्र राज्य** (नोंदणी क्र. पुणे/००००२३५०/२०२५) ही महाराष्ट्रातील ऐतिहासिक गडकिल्ले संवर्धन, दुर्ग अभ्यास मोहीम, गरजू विद्यार्थ्यांसाठी शालेय साहित्य वाटप आणि विविध सामाजिक उपक्रमांसाठी अविरत कार्यरत असलेली एक नोंदणीकृत सामाजिक संस्था आहे.

### 🌟 मुख्य कार्यक्षेत्रे (Core Initiatives):
1. **गडकिल्ले संवर्धन (Fort Conservation):** राजगड, तोरणा, सेहवागड, रायरेश्वर, विसापूर, सिंहगड इत्यादी गडकोटांची स्वच्छता, डागडुजी व संवर्धन.
2. **नित्य पूजा व स्वच्छता (Ritual & Sanctity):** गडकोटांवरील मंदिरे, समाधी व मूर्तींची नित्य पूजा, स्वच्छता आणि पवित्रता राखणे.
3. **शालेय साहित्य वाटप (Educational Support):** दुर्गम व आदिवासी भागातील विद्यार्थ्यांना वह्या, पुस्तके व शालेय साहित्याचे मोफत वाटप.
4. **सामाजिक उपक्रम व लाठी-काठी (Social & Cultural):** पारंपरिक मर्दानी खेळ (लाठी-काठी, तलवारबाजी) प्रशिक्षण, रक्तदान शिबिरे व आरोग्य सेवा.
5. **दुर्ग अभ्यास मोहीम (Fort Study Expeditions):** तरुणांमध्ये इतिहास, भूगोल व गडकोटांविषयी जागरूकता निर्माण करण्यासाठी अभ्यास मोहिमा.

## 💻 तंत्रज्ञान (Tech Stack)

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP (ScrollTrigger, Parallax) & Framer Motion
- **Fonts:** Self-hosted Marathi & Devanagari typography (`Mukta`, `Rozha One`, `Yatra One`)
- **Deployment:** Vercel Ready

---

## 🚀 स्थानिक विकास (Local Development)

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

ब्राउझरमध्ये [http://localhost:3000](http://localhost:3000) उघडा.

---

## 🌐 Vercel वर डिप्लॉयमेंट (Deploy on Vercel)

1. GitHub वरून रेपो इम्पोर्ट करा (`https://github.com/efx-143/shivmudra.git`).
2. Framework Preset: **Next.js**
3. Build Command: `npm run build`
4. Output Directory: `.next`
5. Deploy वर क्लिक करा.
